# ربط الحضور والانصراف بجوجل شيت

1. أنشئ ملف جوجل شيت جديد باسم «حضور جادو» (من نفس حساب جوجل الخاص بـ Firebase).
2. من القائمة: **الإضافات ← Apps Script**.
3. احذف الكود الموجود في `Code.gs` والصق محتوى `all.gs` كاملًا (يجمع core.gs و server.gs):
   https://raw.githubusercontent.com/companyjadu-sketch/JADU-APP/main/apps-script/all.gs
4. اختر الدالة `setup` واضغط **تشغيل** مرة واحدة، ووافق على الصلاحيات.
   تُنشأ الأوراق: الموظفون، القواعد، سجل التعديلات، ومشغّل يومي يسجّل الغياب الساعة 9 مساءً.
5. **نشر ← نشر جديد ← تطبيق ويب**: التنفيذ باسم «أنا»، والوصول «أي شخص». انسخ الرابط المنتهي بـ `/exec`.
6. ضع الرابط في `attendance.js` بالمتغير `ATT_API_URL`، ورابط الشيت في `ATT_SHEET_URL`.

الموظفون يختارون أسماءهم مرة واحدة على هواتفهم. إضافة موظف أو إيقافه من صفحة الإدارة.
